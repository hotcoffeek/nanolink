# NanoLink

Двухпанельный обмен файлами: телефон ↔ ПК, ПК ↔ Steam Deck, ПК ↔ ТВ-приставка.
Один код на Flutter: Windows, Android (APK), Linux (Steam Deck).

## Как собрать (GitHub)
1. Создайте репозиторий на GitHub, загрузите в него всё содержимое этой папки (включая `.github`).
2. Вкладка **Actions** → **Build NanoLink** → **Run workflow** (или просто push в `main`).
3. Через 5–10 минут внизу страницы запуска в **Artifacts**: `NanoLink-windows` (zip с .exe), `NanoLink-android` (APK), `NanoLink-linux`.

Папки `windows/`, `android/`, `linux/` создаёт сама сборка (`flutter create`), в репозитории их нет.

## Запуск
- **ПК**: распакуйте zip, запустите `nanolink.exe`. Брандмауэр Windows спросит доступ - разрешите для частной сети (TCP 47322, UDP 47321).
- **Телефон**: установите APK, откройте, выдайте «доступ ко всем файлам» (кнопка в проводнике или в Настройках), в Настройках отключите оптимизацию батареи.
- Устройства с NanoLink находят друг друга сами. Первое подключение подтверждается один раз на экране устройства, дальше - без вопросов.

## Steam Deck и ТВ-приставка
- Steam Deck: включите SSH (`passwd`, `sudo systemctl enable --now sshd`) и добавьте через «Добавить по IP» / сканирование - подключение по SFTP. Либо запустите Linux-сборку NanoLink прямо на Deck.
- ТВ-приставка: включите FTP или SMB-сервер на ней, сканирование определит её по портам, логин/пароль спросит при первом подключении.

## Как держится связь
- Сокеты привязаны к реальному Wi-Fi/Ethernet адаптеру, VPN-адаптеры игнорируются; на Android процесс привязывается к Wi-Fi и работает как служба.
- Каналы с пульсом раз в 5 с; при обрыве - поиск устройства заново (MAC / имя / порты по подсети), затем докачка с того же байта (`*.nlpart`).

## Честно о границах
- Код ещё не компилировался - собрать у меня было нечем. Если Actions покажет ошибки, пришлите текст ошибки или скриншот, поправлю.
- Трафик NanoLink не шифруется (только локальная сеть); доступ защищён подтверждением и общим секретом (HMAC).
- SMB/SFTP-сокеты стороннего кода не привязываются к адаптеру: если VPN перехватывает маршруты локальной сети, включите в VPN «обход локальной сети».
